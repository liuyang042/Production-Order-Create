## 项目背景

本项目旨在标准化TOPT公司经编常规工单的开单操作流程，确保从备胚到成品生产的每一步都有明确的指引。本流程涵盖两种主流生产模式，并集成了SAP系统关键操作，适用于内部培训及日常操作参考。
